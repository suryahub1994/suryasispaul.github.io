# 🌐 suryasispaul.me

Personal website of **Suryasis Paul** — engineer, reader, runner, and writer (English & বাংলা).
This site showcases my portfolio, blog, and now page, with a clean, responsive design built on **Bootstrap 5**.

---

## 🚀 Features
* **Glassy navigation bar** with hover states.
* **Hero section** with call-to-action buttons.
* **About section** with profile avatar, bio, and social links (GitHub, LinkedIn, résumé download).
* **Common footer** with site navigation and auto-updating year via JavaScript.
* **Background design** combining gradients with a Bengali letters SVG pattern.
* **Accessibility friendly** (semantic HTML5, reduced-motion support, alt text for images).

## 📦 Setup & Usage

1. Clone the repo:

   ```bash
   git clone https://github.com/<your-username>/<repo-name>.git
   cd <repo-name>
   ```
2. Open `index.html` in your browser to view locally.
   *(No build step required, it’s a static site.)*
3. To serve locally with live reload (optional):

   ```bash
   npx serve
   ```

   Then visit [http://localhost:3000](http://localhost:3000).
